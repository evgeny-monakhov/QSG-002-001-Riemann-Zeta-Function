# QSG-002-001-Riemann-Zeta-Function
Program for numerical verification of the spectral reformulation of the Riemann Hypothesis. Calculates the QSSC profile of an integer operator (HZ​) to show that Zeta zeros coincide with spectral resonances, validating the proposed self-consistency law.

================================================================================
SPECTRAL REFORMULATION OF THE RIEMANN HYPOTHESIS
AS A LAW OF SELF-CONSISTENCY FOR AN INTEGER OPERATOR
================================================================================

Repository for Note QSG-002-001.
Status: Experimental / Research Prototype

DESCRIPTION
-----------
This repository contains the software implementation for the numerical 
verification of the Quantum Spectral Self-Consistency (QSSC) criterion for 
the Riemann Zeta function. 

The program implements a fast spectral solver for an integer operator (H_Z) 
in Python, demonstrating that Riemann zeros emerge as resonances of a 
self-consistent spectral law, rather than eigenvalues of a specific operator.

KEY FEATURES
------------
* High-Performance Computing: 
  Utilizes Numba (JIT) for compilation, achieving calculations up to 1000x 
  faster than standard arbitrary-precision libraries (like mpmath) at high 
  altitudes (T > 100,000).

* Dual-Method Approach: 
  Implements two distinct algorithms for cross-verification:
  1. QSSC-Linear (Complexity O(T)): A direct, physically rigorous summation 
     of the spectral wave function.
  2. RS-Spectral/Mirror (Complexity O(sqrt(T))): An accelerated algorithm 
     using asymptotic phase mirroring (Riemann-Siegel analogy) for rapid 
     scanning.

* Visualization: 
  Generates phase portraits and |Z(t)| profiles, marking found minima 
  against true Riemann zeros.

* Precision: 
  Capable of resolving Lehmer pairs and locating zeros with high accuracy 
  using a hybrid "Scan & Drill" strategy.

Subsequent runs will be instantaneous.

CONFIGURATION
-------------
You can adjust the search range and precision directly inside the 'main()' 
function of the script file:

  TARGET_T = 100000.0     # Starting height (t)
  TARGET_W = 20.0         # Window width (delta t)

* TARGET_T: The imaginary part of s where the scan begins 
  (e.g., 100.0, 10000.0, 1000000.0).
* TARGET_W: The width of the search window. For very high T, keep this small 
  (e.g., 20.0 or 50.0) to avoid long rendering times for the QSSC-Linear method.

METHODOLOGY
-----------
The program validates the hypothesis that the zeros of Zeta(s) coincide with 
the minima of the QSSC profile generated by the integer operator H_Z:

  Z_Z(u,s) = Sum_{n >= 1} [ w_n * (u^2 + n^2)^(-s/2) ]

* QSSC-Linear: Sums thousands of cosine waves corresponding to integer 
  frequencies. It is physically exact but computationally expensive at large T.

* RS-Spectral: Applies a "mirror symmetry" principle similar to the 
  Riemann-Siegel formula, reducing complexity to O(sqrt(T)). This method 
  allows for real-time scanning of heights up to T = 10^12 and beyond.
